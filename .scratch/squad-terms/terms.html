Careful: words that look alike

These pairs cause mistakes. The repo uses each word, but no file sets them apart.

  • HANDIN and ## Handover. HANDIN is a message: a Developer gives a finished task to QA. ## Handover is a plan section: the Tech Lead writes it when a scope moves up in size. verified process.md:78, process.md:59
  • Squad, scope, pod. A squad has one goal. A scope is one part of that goal. A pod is the roles that deliver one scope. verified process.md:28
  • Role, agent, session. A role is a job (agents/ba.md). An agent is one live copy with a name (a row in roster.md). A session is the Claude Code process behind it. inferred from how README.md and roster.md use the words; no file defines them
  • "Done" changes with size. In S, the Tech Lead review passes it. In M and L, both QAs pass it. verified process.md:34-37
