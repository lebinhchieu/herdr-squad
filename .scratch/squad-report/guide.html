Scope report and rollup: how it works

squad plugin 0.4.0 · tool bin/squad-report · zero LLM tokens, no network
Each teammate builds one data.json per scope in their own squad and sends it to you (with --redact if the text is private). You put the files in one folder and run one rollup command. Nothing leaves their machine except that file.

Teammate (own squad)

1
Finish or pause a scope (running scopes work too; the report is marked partial).
The squad-close hook also builds the report automatically; a failure only warns, never blocks.verified
2
Build the report from the scope's squad: 
squad-report <scope>            # report/data.json + report.html
squad-report <scope> --redact   # same, no titles, no return reasons
Prints the path of report.html and a 5-line summary. Refuses (exit 2) when the scope has messages but no transcripts.verified
3
Check it is current 
squad-report status <scope>   # fresh 0 | stale 3 | missing 4
4
Send only data.json (from <scope folder>/report/). Add report.html next to it if you want the rollup to link to it.verified
5
Optional, on their side: ask what the numbers say: /squad:squad-report-analyze (chat only, reads the digest).

PO (you)

1
Collect the files into one folder, one subfolder or file per scope: 
team/alice-invoices/data.json
team/bob-login/data.json
2
Run the rollup (folders are searched for data.json): 
squad-report rollup team/ --out ./squad-rollup
# or in Claude: /squad:squad-report team/alice-invoices/data.json team/bob-login/data.json
Output: ./squad-rollup/ with a rollup report.html. It never opens transcripts, squads or paths.verified
3
Read it: totals (time, cost, tokens), one row per scope, working / blocking / waiting split, returns per scope.
4
Your own scopes or a goal: squad-report <scope|goal>; a goal rolls up its scopes from the squad folder.
⇄ handover: data.json (portable: ids, numbers, roles, times; no absolute path, no transcript text)

What is in the file (privacy)

IncludedLeft out
Ids, counts, roles, durations, cost, ticket/escalation titles, return reason (first 200 chars of each FAIL)Prompts, transcripts, other messages, absolute paths
With --redact: titles and return reasons removed too. Use it when the work is private. A reason can name a path or secret an agent typed, so redact when unsure.

Prices come from the teammate's config, so cost differs if their price table differs. Other Claude accounts' transcripts are invisible to the toolknown gap, backlog.

Ask teammates for this one thing: "Run squad-report <scope> --redact and send me report/data.json." Tip: tell them to name the file <squad>-<scope>.json when sending, since all files are called data.json.
