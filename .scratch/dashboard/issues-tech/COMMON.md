# Common technical AC (QA whitebox: board-qaw-dashboard)

Apply to every ticket that adds or edits code under `bin/`, `templates/board/` or `tests/`. A ticket file lists which ones apply. A FAIL names one id. Binding together with `tasks/issues/NN-*.md` (business AC) and `architecture.md` (final).

| Id | Criterion | How QA whitebox checks it |
|---|---|---|
| TC.1 | **Architecture.** The diff matches `architecture.md` sections 1 and 6: file names, module-per-reader, reader contract `read(selection) -> {data, quality, unknown:[source]}` (never raises; missing source gives `unknown:<source>`), `schema_version` in every API response, additive only. A difference is a finding unless the Developer got an `ANSWER` from the owner (MSG-20). | read diff against the touched-files list of the ticket and section 6 |
| TC.2 | **Read-only.** The board writes only `<squad folder>/board-ui.json` (ticket 09). No other write into the squad folder, the repo or the home dir. The inbox is read with `squad-inbox list --json --no-write` (plain `list` writes `seen` events). `grep` of the diff for `open(.., "w"/"a")`, `write_text`, `os.replace`, `mkdir`, `touch`, `git` write commands (`commit`, `checkout`, `add`, `branch -`, `worktree add`) finds none outside `board-ui.json` code and temp dirs of tests. | `grep -nE` over the diff; the test for the reader snapshots the fixture folder (file list + mtimes + sha) before and after `read()` and asserts it is equal |
| TC.3 | **Stdlib only.** No import outside the Python standard library and the repo's own `bin/` modules; no `pip`, no CDN, no `<script src="http...">` or `https://` URL in `templates/board/`. | `grep -nE "^(import|from) "` on new files; `grep -rn "http" templates/board/` |
| TC.4 | **Windows (ADR 0011).** `pathlib` for paths; every text `open` names `encoding="utf-8"`, writes add `newline="\n"`; no module-level `import fcntl`; `subprocess` text mode names `encoding=`; `git`/`herdr` called by name, not by path; no bare `"bash"`/`"sh"` argv. A CLI calls `squadio.utf8_stdio()` first in `main`. `tests/test_windows_safe.py` and `tests/test_no_bare_bash.py` pass (they scan all of `bin/`, so they must be run on the final diff). | run those two files; read diff |
| TC.5 | **Old-language inventory.** `tests/test_old_language_inventory.py` scans `bin/` for `size:`, `'size'`, `"size"`, `qa-b\b`. A new file must add no hit: name a JSON key `span`/`bytes`, not `size`; do not write `qa-b`. | run that test file; it must pass without a new ALLOW entry |
| TC.6 | **Test economy.** One test file per reader, named as in `architecture.md` section 6. Every test traces to a business or technical AC id, named in its docstring or name (`test_T04_AC3_...`). No matrices, no input sweeps, no tests of getters or constants. Existing test files only get additive edits; none newly skipped. | read test file; count tests against AC ids |
| TC.7 | **Real samples (REV-4).** A reader that parses another tool's output (herdr JSON, `squad-inbox --json`, git porcelain, ledger text) has at least two real samples in the test: one normal, one idle/empty/constant case. Real = copied from a live run, kept under `tests/fixtures/board/` (or its own subfolder, ticket 02 rules). QA whitebox runs the reader once, read-only, on live data (REV-5b) and writes the result in `evidence/<task>/qa-w.md`. | read fixtures; live run by QA |
| TC.8 | **Never raises, never hangs.** A missing file, missing `git`, missing `herdr`, unreadable file, bad JSON or a CRLF file gives `unknown:<source>` (or the documented empty value), not an exception. A subprocess has a timeout. | the reader's test has one broken-source case per source it reads (not one per field) |
| TC.9 | **Payload shape (REV-6).** Every row has every field the consumer ticket reads; every closed or ended item has its end field. Tests assert the field set of a row, not only counts. | read test assertions; compare to the consuming ticket's rules |
| TC.10 | **No spill into other tickets' files.** The diff touches only the files in the ticket's "Touched files". A fixture file goes only in the ticket's own subfolder of `tests/fixtures/board/`. | `git diff --stat <base>..<sha>` |
| TC.11 | **Greps over tests (CLAUDE.md).** For a diff that touches `templates/` or text a `bin/` tool prints: the Developer ran `grep -rl '<touched path or changed string>' tests/` and ran every hit. The HANDIN lists the grep and the hits. | QA re-runs the grep |
| TC.12 | **Hand-in hygiene.** HANDIN names branch and sha; tests for the touched files pass; `git status` clean; no stray untracked files in the repo root; evidence file `evidence.md` next to the ticket (EVID-1). Full suite is run by QA whitebox once on the final sha, not by the Developer. | `git status`, `git log` |
