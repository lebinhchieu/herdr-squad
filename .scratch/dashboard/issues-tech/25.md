# Technical AC 25: Panels dropdown opens under its button (Tech Lead: board-tl-dashboard)
Common AC that apply: TC.1, TC.3, TC.6, TC.10-TC.12; UI-COMMON TU.1, TU.3, TU.4. No design needed (no new look; same menu, right place). Binding with the BA's `tasks/issues/25-*.md`.

## Design notes
- Cause (read): `.pop` in `board.css` is `position:absolute;right:var(--gutter)` with no `top`, and `els.pop` is appended as the LAST child of `#app` (board.js ~318-319), so it sits at the page bottom. Fix = place it from the button, like the column picker `.cpop` already does (`position:fixed`, computed from the opener's rect, clamped to the viewport; reuse that code, do not write a second one).
- `togglePop` (board.js 558) computes `top = btn.bottom + 4`, `right`-aligned to the button's right edge, clamped inside `window.innerWidth/innerHeight` (if no room below, open above). Recompute on window `resize`, on `scroll` of the page while open, and after `renderPop` (the list height changes when a panel is shown). Closing rules stay: click outside, Esc, toggling the button.
- Keep `aria-expanded`, `role=menu`, `menuitem` buttons. Keep the focus ring. Colours: existing tokens (no new hex outside `:root`).
- Files: `templates/board/board.js` (the position function; one place), `templates/board/board.css` (`.pop`: `position:fixed`, drop `right`). 26 also edits both files: 25 first, same Dev.
