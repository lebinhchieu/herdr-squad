## Design notes
- Click code today: `panel_files.js` ~l.177-215 (`link.target = "_blank"`, a markdown preview via `root.open("", "_blank")`). Delete both; the `dataset.md` branch is removed, not hidden.
- **One link function** `BOARD.vscodeUrl(abs, distro)` (pure, in `panel_files.js`, exported on `BOARD`; the Tasks panel calls it). Default `vscode://file/` + each path segment through `encodeURIComponent`, joined by `/` (so `/` stays; unicode and spaces survive; a Windows drive segment `C:` keeps its colon). With `distro` set: `vscode://vscode-remote/wsl+<distro>` + the same encoded path. Empty/undefined `abs` gives `null` (no link). The link always starts with a fixed prefix, so no `javascript:` can result.
- **O1 (WSL) answered: PO agrees (E11, 2026-11-04).** Build exactly the BA's rule: the WSL form when `data.wsl_distro` is set, else `vscode://file/<abs>`. `wsl_distro` = `os.environ.get("WSL_DISTRO_NAME")` or `null`, added by the server beside `rows`. AC6 is not signed off until the PO answers; the form is the one line in `vscodeUrl`. Nobody has tried either form by hand on the PO's setup.
- **Row link:** `<a href>` set by property, no `target`, no `window.open`, `rel="noopener noreferrer"`. The whole row is the link (file, folder, ticket, md, html). Tooltip (`title`): `<abs path> — opens in VS Code` (T30.AC9).
- **Status line (design-v7 §6, T30.AC12):** the click handler (it does not `preventDefault`; the browser follows the link) also sets a `div[role=status]` at the top of the Files panel body: `Sent to VS Code: <abs>` and a `Copy path` button (`navigator.clipboard.writeText(abs)`; if the Clipboard API is missing or rejects, select the text in a hidden input and `execCommand("copy")`, still no error text). A timer of 8000 ms removes it; a second click replaces the text and restarts the timer. A re-render of the panel (poll, resize) must not drop a line that is still within its 8 s: keep it in module state and redraw it. Text via `textContent` (TU.3).
- **Folder cell (T30.AC13):** name in bold as the link, and under it the absolute path in small muted text; it lives in the File cell so it stays when other columns are hidden. The Tasks Where cell: repo-relative text, underlined link to `vscodeUrl(abs)` where the row has `abs` (28 provides `abs`). Folder part muted, file name bold (design).
- **Outside the roots (T30.AC7):** the server never lists such a file (today's `add` check), so the page cannot get a link for it. The "muted plain text, What `cannot be opened: outside the squad folders`" row needs the server to return the symlinked-out file as a row with `abs: null` and `what` set to that text; `add` currently drops it. Change: for a symlinked file whose target is outside the roots, append a row `{kind: "other", what: "cannot be opened: outside the squad folders", abs: null, blocked: true, path: <squad-relative link path>}`; the page draws a row without `abs` as plain muted text. It must count in `files_seen`. The target path is never given to the page. If the BA/Designer prefer no row, say so; the BA's AC7 is the contract.
- Local only: absolute paths appear in `/api/files` on 127.0.0.1 with the Host check (ADR 0020); named in the ADR note (promote.md). `/api/file` stays in the server, unchanged (T14.AC6 sandbox still holds for the route).

## Technical AC
- **T30.TA1 URL function.** `BOARD.vscodeUrl`: `/home/me/a b#c.md` -> `vscode://file/home/me/a%20b%23c.md`; with distro `Debian` -> `vscode://vscode-remote/wsl+Debian/home/me/a%20b%23c.md`; `/home/me/đề-bài.md` -> `vscode://file/home/me/%C4%91%E1%BB%81-b%C3%A0i.md` (AC5); `C:\Users\me\x.md` -> `vscode://file/C:/Users/me/x.md`; empty -> `null`; `javascript:alert(1)` -> `vscode://file/javascript%3Aalert(1)`. One test, table of cases. Decoding each segment gives the path back.
- **T30.TA2 No tab, anywhere (AC10).** `grep -n "_blank\|window.open\|root.open" templates/board/*.js` has no hit for a file link (a hit for something else is named in HANDIN). Rendered rows of every kind (md, html, json, `.scratch` file, folder, ticket) have `href` starting `vscode://` and no `target`. Tasks Where cell same.
- **T30.TA3 Data.** Rows carry `abs` (equal to the resolved path, inside the roots). `data["wsl_distro"]` is the env value or `null` (test sets and unsets `WSL_DISTRO_NAME`). The page passes it to `vscodeUrl` (AC1, AC6; both forms rendered in one test).
- **T30.TA4 Untrusted text is text (TU.3).** A file name `<img onerror=x>` shows as text; `href` set by property; the status line shows the path as text.
- **T30.TA5 Tooltip (AC9).** Link `title` contains the absolute path and `opens in VS Code`.
- **T30.TA6 Status line (AC11, AC12).** Click a row: `[role=status]` with `Sent to VS Code: <abs>` and a `Copy path` button; after 8 s (fake clock or a short injected timeout, not a real 8 s sleep) it is gone; a second click within 8 s shows the new path and restarts the timer; a panel re-render inside the 8 s keeps it. `Copy path` calls the clipboard with the abs path (stub `navigator.clipboard`). A click that opens nothing changes no other state: panel layout, scroll and choice in the saved UI are the same; no `alert`, no error text.
- **T30.TA7 Folder and outside rows (AC3, AC7, AC13).** A folder row renders name + abs path line in the File cell and the path line is still there with only the File column shown. A symlink-out fixture gives a muted row without `href`, What `cannot be opened: outside the squad folders`, and no `..` path ever reaches `vscodeUrl`.
- **T30.TA8 Read-only (AC8).** No new server route (diff of `squadboard.py` routes empty); hashing the fixture squad before and after a session of clicks changes nothing except `board-ui.json`.
- **T30.TA9 Old pins changed on purpose.** The 29/T14 test "symlink out is not listed" changes for files (the row is kept, `abs` null, `blocked` true; folder rows stay not listed). `tests/test_squadboard_panels.py` ~l.674 (`_blank`) and any test reading `Opens in a new tab` / `dataset.md` are rewritten; HANDIN lists each. None skipped.
- **T30.TA11 Tasks Where link (AC4, AC13).** The Tasks `where` cell shows the repo-relative path as text (folder part muted, file name bold) and the link has `href` = `vscodeUrl(abs, distro)`, no `target`; a row without `abs` (plan rows) shows text only.
- **T30.TA10 Live check (REV-5b).** QA whitebox reads the rendered `href` in headless Chrome `--dump-dom` for a real row of the dashboard scope, with and without `WSL_DISTRO_NAME`. Opening VS Code is QA blackbox's by-hand check; evidence is a note, not a screenshot of VS Code.
- **Tests:** `test_squadboard_panels.py` (Files + Tasks Where part; new tests in a class at the END of the file, 28 does the same), `test_squadboard_files.py`. Grep rule (TC.11): `grep -rl "panel_files\|panel_tasks\|_blank\|api/file" tests/`; run every hit.
