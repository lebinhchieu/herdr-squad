# Common technical AC for the page tickets 10, 11, 12, 13, 16 (QA whitebox: board-qaw-dashboard)
Apply TC.1, TC.3, TC.6, TC.10, TC.11, TC.12 plus the rows below. The presentational values (colours, sizes, gutter, fonts) are the mock's and QA blackbox's (REV-18a): whitebox does not assert them, it checks structure, safety and testability only.

| Id | Criterion | How checked |
|---|---|---|
| TU.1 | **Logic is callable without events.** Every rule the AC states (layout pack, age words, time/zone format, tab title, search filter, Recent list, "N new" counts, needs-you total) is a plain function on one namespace (e.g. `window.BOARD`) with no DOM access, so a test page can call it. A rule that exists only inside an event handler is a finding. | read JS; the unit test calls them |
| TU.2 | **How the page is tested.** Python has no Playwright here and the repo is stdlib-only. Page logic tests use headless Chrome `--dump-dom` on a small harness HTML written to a temp dir that loads the real `templates/board/*.js` and prints results into the DOM (pattern of `tests/test_squadreport_ui.py`). Interaction (drag, clipboard, Esc, real resize, tab hide) is QA blackbox's by `playwright-cli`; whitebox checks that its hooks exist (TU.1). Browser test files carry the existing `skipUnless(CHROME, ...)` pattern; QA whitebox's run on this machine must show them **run, not skipped**. | read test; suite receipt shows 0 skipped in these files |
| TU.3 | **Untrusted text is text.** Titles, FAIL reasons, question text, brief, names come from agent-written files. They reach the DOM only through `textContent` / `createTextNode`; no `innerHTML`, `outerHTML`, `insertAdjacentHTML`, `document.write`, `eval`, `new Function`, `setTimeout(string)` and no inline `on...=` attributes with data. Check: `grep -nE "innerHTML|outerHTML|insertAdjacentHTML|document\.write|eval\(|new Function" templates/board/` returns nothing (a static literal template with no data is allowed only if the Developer lists it in HANDIN). Test: a ticket title `<img src=x onerror=window.__x=1>` is shown as text and `window.__x` stays undefined. | grep + harness test |
| TU.4 | **No remote anything.** No `http(s)://` URL, `@import`, web font, CDN, `<link rel=preload>` to another origin in `templates/board/`; the page uses relative `/static/` and `/api/` paths only; `fetch` calls carry no credentials to other origins. | `grep -rnE "https?://" templates/board/` (allow `http://www.w3.org/2000/svg` only) |
| TU.5 | **Token and writes.** The token is read once at load; the only `fetch` with a method other than GET is `PUT /api/ui` (ticket 09), sent with the token header. No other write: no `POST`/`DELETE`, no form. Copy-only commands use `navigator.clipboard.writeText` with a fallback; they never call an API. | `grep -n "method" templates/board/*.js` |
| TU.6 | **Static files.** One panel = one file registering `PANELS.x` + `COLDEF.x` as in `proto-v5.html`; cutting a panel = delete the file and its name in the order list (architecture §1a). Files are served by `/static/<name>` with the allow-list of file names in `templates/board/` (no path traversal; checked in 03). Files are UTF-8, LF, no BOM, no build step, no minified code, no source maps. | `ls templates/board`, `file` |
| TU.7 | **Polling.** One timer; 5 s; a refresh that is still running is not started again (no pile-up); failures counted, "not updating" after 3, reset on success; timer is cleared when the tab is hidden **only** if the ticket says so (13 uses visibility, not the timer). `fetch` has a timeout (e.g. `AbortController` 4 s). | read; harness with a stub fetch |
| TU.8 | **Fixture not mock.** The page tests read their data from the ticket-02 fixture through `squadboard` (real server or direct reader output saved as JSON), not a hand-typed JSON that can drift from the API shape. `schema_version` is checked by the page: an unknown version shows "unknown: board version" and does not render stale data. | read test |
| TU.9 | **Design conformance is blackbox's.** The Developer follows `ui-design/design-v5.md` (`Status: final` before the ticket starts, LC-2b). If the file is not final when the HANDIN arrives, QA whitebox returns the task. Whitebox only checks that there is no CSS value outside the token block `:root{...}` that duplicates a token (colours as `var(--x)` everywhere else; no hex outside `:root`). | `grep -nE "#[0-9a-fA-F]{3,8}" templates/board/*.css` outside `:root` |
