## Design notes
- **Flow:** `squad-board --demo [--port N] [--no-open]` -> `squadboard_demo.run(argv)`: refuse `--squad/--goal/--scope` with exit 2 (BA); `board_fixtures.copy_fixture(now=utc_now)` (times shifted so ages read "40 min"); extend the copy (below); set `HOME`, `USERPROFILE` and `CLAUDE_CONFIG_DIR` to folders inside the copy and delete `SQUAD_DIR`, `SQUAD_NAME`, `SQUAD_SCOPE`, `SQUAD_ROLE` from the env, so nothing real can be read; call `squadboard.main(["--squad", <copy squad>, "--goal", "alpha", "--herdr-json", <copy herdr file>, ...passed --port/--no-open])`; print one line `demo: sample data in <copy path>`; remove the copy in a `finally` (Ctrl-C and `SIGTERM`: install a handler that raises `KeyboardInterrupt` so `kill PID` also cleans, T37.AC10). Exit codes as today (1 busy port). The server is unchanged: it has `--squad PATH`, `--goal`, `--herdr-json`, `--no-open`.
- **Opens on goal `alpha`** (BA: the Scopes panel exists only in a goal view; all six panels must have content). **BA fact I confirmed in the fixture: goal `alpha` has no question, tickets, messages or transcripts; the content sits in the lone scope `checkout`/`questions`.** So the demo copy is extended after the copy step, by code in `squadboard_demo.py` (not by committed fixture edits, so the goldens of `test_board_fixtures.py` stay): give `alpha`'s scopes what `checkout` has (messages with the task stages, an open question and a blocked agent, `tickets:` line + ticket files, roster with session ids, transcripts with a night gap and the DST gap, herdr agents for the roster names in `agents.json`, files rows of every kind: md, html, folder, ticket). Simplest route for the Dev: copy `checkout`'s files into `alpha-api` and rename `fix-*-checkout` to `fix-*-alpha-api` in names; the Dev checks T37.TA2 on both the goal view and `checkout`. The shared fixture is not edited.
- **Touches no real squad data (BA AC7/AC8):** the only squad is the copy; the file click route (34) works on the copy's files. QA blackbox's test: a unique `REALSQUAD-<random>` squad/transcript in the real repo/home never shows up.
- **Label (page, BA text):** `/api/squads` gets `"demo": true` (one key, only in the demo); the page shows `DEMO · sample data, not your squads` in every view, no close control, text only (TU.3), and the tab title starts with `[demo]` (the title function in `board.js` rewrites the title on each update, so the prefix goes there). Place: the Designer's, in design-v8 or a note; it must not push the banner, picker or top bar. This is the only change in `squadboard.py` and `board.js`: it is the **last step**, after 34 and 36 are merged to the Dev's base (shared files). The Manager may split it as 37b.
- **Saved UI:** `board-ui.json` is written into the temp copy only and is deleted with it; a PO's real `board-ui.json` is never touched. State: the demo starts with the default layout every time.
- Windows: `tempfile` + `shutil.rmtree`, no `fcntl`, UTF-8; `bin/squad-board` already sets `squadio.utf8_stdio()`.
