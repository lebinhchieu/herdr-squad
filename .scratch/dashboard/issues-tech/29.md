## Design notes
- **Folder rows are a separate list.** `list_files` returns a new additive key `folders`: a list of 0-2 rows `{name, kind: "folder", what, scope, path, abs, mtime}`. They are NOT in `rows`, so `files_seen`, `truncated`, the MAX_ROWS cap, the sort and `report` are untouched (T29.AC10), and the page draws them above the sorted rows (page side: ticket 30 / panel_files.js). Order in `folders`: `.scratch` first, squad folder second. `KINDS` gets `"folder"`; `WHAT["folder"]` is not used (each folder row sets its own `what`: `Repo tickets folder`, `Squad folder`, design-v7 §6).
- **Row 1 `.scratch`:** `squad.repo_root / ".scratch"`. Shown only if `real = resolve(strict)` is a directory and `squadboard._under(real, roots)` (a `.scratch` symlink to outside gives no row: T29.AC6). `name` = `.scratch`, `abs` = `str(real)`, `path` = `abs` (same as file rows under `.scratch` today), `mtime` = `int(real.stat().st_mtime)`.
- **Row 2 squad folder:** `squad.path`. `name` = `squad.path.name` (the squad folder's name, e.g. `board`, BA T29.AC1 as re-read 2026-11-04). Same `abs` / `path` / `mtime` rules (`path` = `abs` for both folder rows: they never go through `/api/file`).
- **Goal and scope views both** get `folders` (T29.AC2). They are built before the kind branch in `list_files`. Missing or unreadable folder: that row is left out, never raises (extends T14 "never raises").
- **Ticket rows** come from `squadtickets.scope_tasks(home, squad.repo_root, name)` (one reader; no second copy of the folder guess). For each task with `abs` inside the roots: `w.add(Path(abs), "ticket")` and the row's `what` = the task title (T29.AC11; design-v7 §6: What = title, cut by the page). If `source` is `declared` or `scratch`: also `spec.md` next to the `issues/` folder (`Path(dir).parent / "spec.md"`), kind `ticket`, if it is a regular file. Source `scope`: the same call lists `tasks/NN*.md` and `tasks/issues/NN-*.md` (T29.AC4). Source `plan` or `None`: no extra rows. Another scope's ticket folder is never listed because `scope_tasks` never returns one (T29.AC5).
- **Dedupe (T29.AC9):** `_Walk` keeps a set of resolved paths; `add` skips a path already listed. The ticket rows are added first, so their `what` (title) wins over the old `tasks/*.md` walk (`ticket plan`).
- `add` needs one optional argument `what=None` (default `WHAT[kind]`); row shape stays the six keys plus `abs` (30 adds `abs` to every row; 29 may already add it, same Dev).
- Do not list: `messages.jsonl`, `inbox.jsonl`, `roles/`, locks, `_runtime`, ADRs. No file is opened or read, names and mtimes only.

## Technical AC
- **T29.TA1 Folder rows.** Fixture squad with a `.scratch`: `data["folders"]` has two rows with names `.scratch` and the squad folder's name, `what` `Repo tickets folder` / `Squad folder`, kind `folder`, `abs` equal to the real folder, `mtime` equal to `os.stat` of the folder. Same in a goal view (T29.AC1, AC2). One test over both views.
- **T29.TA2 Always, and not counted.** A scope with no files at all still gives both rows; `files_seen`, `truncated` and `len(rows)` do not count them (T29.AC3, AC10).
- **T29.TA3 No `.scratch`, or a symlinked one.** No `.scratch` folder: one folder row, no error. `.scratch` as a symlink to `/tmp/x`: no row for it, nothing raised (T29.AC6). Allow-list holds: every folder row passes `_under(real, roots)`.
- **T29.TA4 Ticket rows from `scope_tasks`.** Fixture `accounts/cswitch-bg` layout (flat `tasks/01.md`..`04.md`): rows `tasks/01.md`..`04.md` kind `ticket`, `what` = the title. Fixture with `.scratch/<slug>/issues/NN-*.md` and `spec.md`: all listed, kind `ticket`. Another scope's `.scratch/other/issues/..` not listed (T29.AC4, AC5).
- **T29.TA5 Once.** A file reachable by two rules (a `tasks/NN.md` ticket, or a ticket `evidence.md`) is one row (T29.AC9). Assert unique `path` over `rows`.
- **T29.TA6 Row shape (REV-6).** Every row in `rows` and `folders` has `name, kind, what, scope, path, mtime`; `kind in KINDS`; `abs` present. Two ticket rows are fetched through the handler's `/api/file` (200) so the old route still serves them.
- **T29.TA7 Old behaviour.** The existing Files tests (T14.AC1, AC3, AC4, AC5: kinds, allow-list, symlink out not listed, 600 files give 500 rows and `truncated: true`) stay green; none edited except to add the `folders` key. The goal test stays green.
