The 7 real defects (what light QA keeps)

BRD-03 · a blank table row became a needs-you item that can never clear

bin/squad-board ~305-311 derive_needs_you: a row of empty cells (| | | | |) has an empty Answer cell, so it was listed as escalation:<row> with empty text.

Found by reproducing with a fixture · fixed round 2 (fe5eda2) · verified

BRD-09 · one FAIL counted as three returns (spec rule D1)

A verdict goes to the Developer and is copied to the Manager and Tech Lead; each copy is its own log record, so one FAIL tripped the "3 returns, Manager steps in" rule falsely.

Found by running on the real squad log · fixed in BRD-18 (e9ca502) · verified

BRD-09 · a finished task went back to "building" (spec rule D2)

After PASS, a later STATUS or DECISION mentioning the task reopened it.

Found on real data · fixed in BRD-18, done is now sticky · verified

BRD-12 · page and server disagree on who the Manager is

bin/squad-board.html:245 role === 'Manager', but the server lowercases first, so a roster role manager showed the wrong pod size.

Found by reading both sides · fixed round 2 · verified

BRD-13 · an arrow arriving off-screen keeps the page redrawing forever

Breaks E16 (animate only when something moves). Probe: 60-message history, scrolled to top, one message appended.

requestAnimationFrame calls in 2.5 s
append off-screen : 51   1
control (no append) : 0

1 a hot idle loop on a live board nobody is watching. Found by a probe script · fixed 3cea6e6 · verified

BRD-15 · the token appears in a response body (security)

GET /notes/dev board?token=<T> HTTP/1.1
400 {"error": "Bad request syntax ('GET /notes/dev board?token=<T> ...')"} 1

1 the AC says the token never appears in any body or header. Low risk (only the sender sees it) but the AC is literal. Found by a hostile probe · fixed 09cf802 · verified

BRD-06 · a huge env knob breaks the server (operator-only)

SQUAD_BOARD_REQUEST_TIMEOUT_S=1e300 made every request fail; POLL_S=1e300 killed the watcher thread. Capped at one day in d057b06.

Found by probing the knob validation · inferred that it was not a mutant find
