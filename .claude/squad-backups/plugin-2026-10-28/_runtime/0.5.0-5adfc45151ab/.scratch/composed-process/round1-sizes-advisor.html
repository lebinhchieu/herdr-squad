Opus advisor: how it works

Sonnet role working→ hard problem / 3rd FAIL / stuck→ calls advisor (Opus reads the transcript)→ advice in the same turn
  • Turned on with "advisorModel": "opus" in role settings. Subagents inherit it. docs + probe
  • The model decides when to call it. There is no setting to force or cap calls, so "must consult at the 3rd FAIL" has to be a rule, plus a hook reminder (ticket 12's 3-return notice).
  • Toggling it doesn't break the main prompt cache, but the advisor's own read of the transcript isn't cached. On a subscription it counts against plan limits.
  • The advisor needs the Anthropic API, so it doesn't work on Bedrock or Vertex. Experimental.

Cost tie-in: this replaces cost rule 4 (step up one notch of model on failure). Switching a model mid-session breaks the cache; the advisor doesn't.
