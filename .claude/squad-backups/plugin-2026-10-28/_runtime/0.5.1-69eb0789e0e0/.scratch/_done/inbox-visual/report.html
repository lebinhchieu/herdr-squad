3 · Release: what changed for you?

The inbox now reads at a glance instead of as prose. It's still text in the terminal, with no HTML.

  • Item screen. The item's kind, what it blocks, its title and a one-row ✓ recommends (c) pointer all fit in the first 6 rows of a 24-row terminal.
  • Body. Headings, bullets, numbered lists, bold, code, fenced code, tables and [rec] tags now show as structure. Any other markup shows as plain text, so nothing is dropped.
  • Options. Each option is its own block, and the recommended one is marked green. When the screen is narrow, the borders go.
  • Colour. Green means passed or recommended, red means blocking or failed, amber means waiting or warning, and dim is metadata. blocks X turns dim once the work is released.
  • Band and list. The band's counts are never cut off. Each group shows 7 rows, and +N more opens the rest in place. The "answered, waiting for the Manager" group is coloured.
  • Unchanged: squad-inbox add and the Manager's instructions. The recommended option comes from the key already written in --rec.
